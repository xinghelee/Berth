Features

Everything a terminal veteran expects, all native

Server dashboard

⌘0 puts every host on one screen: CPU, memory, disk, network and load, each with a CPU trend. Hosts with an open terminal reuse that connection, and polling never throws a dialog at you.

AI assistant on your server

⌘⇧A opens a chat panel; the AI runs commands on the current session with per-command approval. 23 providers built in — Anthropic, OpenAI, Fireworks AI, DeepSeek to Ollama. Keys stay in your Keychain.

Connection reuse & infinite splits

⌘T tabs and ⌘D splits share one SSH channel — no second handshake. Nest splits without limit; exit collapses the pane.

Jump hosts & port forwarding

Chain jump hosts end to end. Local, remote and dynamic SOCKS5 forwarding, plus HTTP and SOCKS5 proxies outbound.

Keys & Touch ID

Generate or import keys. Touch ID verifies once per host per launch before a private key is used, and again after 15 idle minutes or when credentials change. known_hosts pinning with loud alerts on fingerprint changes.

SFTP file panel

Rides the session connection. Drag-and-drop transfers, edit remote files in your local editor with auto write-back, chmod, bookmarks, previews.

Calm about disconnects

Auto-reconnect with exponential backoff, straight back to your working directory (OSC 7). Exit codes marked inline (OSC 133).

Production guardrails

Per-host alert colors, so prod never looks like staging. Broadcast input across sessions; snippets with {{variables}}.

Security

Two hard rules, built into the architecture

  • Secrets stay in Keychain

    Passwords, passphrases and private keys live in the macOS Keychain — never written to disk in plain text. JSON backups carry host structure only, no secrets.

  • Everything stays local

    No account, no cloud. Your host list lives on your Mac, syncs both ways with ssh_config, and moves with you any time.

FAQ

Common questions

Which systems are supported?
macOS 15 Sequoia or later. Ships as a universal binary — Apple Silicon and Intel.
Where are my passwords stored?
In the macOS Keychain only, encrypted by the system. Berth has no servers — there is nowhere to upload them to.
Will my hosts sync across devices?
CloudKit sync is on the roadmap — still no servers of ours; the data only ever lives in your iCloud.
